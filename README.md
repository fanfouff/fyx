# 答辩 PPT 公式关系讲解

围绕 PPT 第 9-11 页：模型问题建模、控制器设计与稳定性判据。

核心主线：

> P9 是“把问题建出来”；P10 是“把控制器接进去”；P11 是“证明它有效”。
>
> 也就是：原系统 → 误差系统 → 控制律 → 闭环误差系统 → Lyapunov 稳定性判据 → 均方指数同步。

## P9：五个公式的含义与联系

### 1. 动态网络弹性同步控制模型

```text
ẋ_i(t)=f(x_i(t))+Σ_{j=1}^{N}G_{ij}(r(t))A x_j(t−τ(t))+B u_i^f(t)
```

含义：第 `i` 个节点的状态变化由三部分决定：自身动力学、带时滞的邻居耦合、实际控制输入。

通俗表达：每个节点一边按自己的规律运行，一边受邻居历史信息影响，还受控制器调节。

### 2. 退化模型

```text
u_i^f(t)=Γ_i(r(t),t)u_i(t)
```

含义：控制器设计出来的是名义输入 `u_i(t)`，真正作用到系统里的是 `u_i^f(t)`。`Γ_i` 表示输入通道有效性。

通俗表达：控制器想打 100 分力，但执行器可能只能打 80 分，甚至带有不确定偏差。

### 3. 同步误差

```text
e_i(t)=x_i(t)−ζ(t)
```

含义：节点状态与参考轨迹之间的偏差。

通俗表达：不直接看每个节点跑到哪里，而是看它离目标轨迹还有多远。

### 4. 误差系统

```text
ė(t)=φ̄(e(t),ζ(t))+(G_m⊗A)e(t−τ(t))+(I_N⊗B)Γ_m(t)u(t)
```

含义：把原来的节点状态模型转化成误差变量的动力学模型。

通俗表达：同步问题被改写成“误差会不会越来越小”的问题。

### 5. 控制目标

```text
E{||e(t)||²} ≤ c e^(−2αt)||φ||²
```

含义：要求同步误差的均方值按指数速度衰减到零。

通俗表达：虽然拓扑随机切换、存在时滞和退化，但从统计平均意义上看，误差要越来越小，而且下降速度有保证。

### P9 公式之间的关系

P9 的关系可以概括为：

```text
原系统 + 输入退化 → 定义同步误差 → 得到误差系统 → 提出让误差指数衰减的目标
```

也就是说，先建立含攻击、时滞和输入退化的复杂动态网络模型，再通过同步误差把“节点是否同步”转化为“误差是否稳定收敛”。

## P10：三个公式的含义、联系以及和上一页的关系

### 1. 控制律

```text
u_i(t)=K_i(r(t))e_i(t)
```

含义：第 `i` 个节点根据自己的同步误差进行反馈控制，并且增益随当前马尔可夫模态变化。

通俗表达：偏差大就调得多，偏差小就调得少；网络处于不同攻击状态时，用不同控制强度。

### 2. 整体形式

```text
u(t)=K_m e(t),    r(t)=m
```

含义：把所有节点的控制律堆叠成一个整体表达式。

通俗表达：把分散在各节点上的控制器写成一个统一矩阵形式，方便后面推导。

### 3. 闭环误差系统

```text
ė(t)=φ̄(e(t),ζ(t))+Ā_m e(t−τ(t))+B_m(I+Δ_m(t))K_m e(t)
```

含义：把控制律代入 P9 的误差系统，同时把输入通道退化写成名义部分加不确定项。

通俗表达：这一式子就是“加上控制器之后，误差如何变化”。

### P10 与 P9 的关系

P9 的误差系统里 `u(t)` 还没设计；P10 给出：

```text
u(t)=K_m e(t)
```

然后把它代入 P9 的误差系统，就得到真正要分析的闭环误差系统。

所以，P9 是“问题建模”，P10 是“控制器接入模型”。

## P11：四个公式的含义、关系和作用

### 1. Lyapunov 泛函总结构

```text
V=V₁+V₂+V₃
```

含义：总 Lyapunov 泛函，由当前误差能量和历史误差能量组成。

通俗表达：构造一个“误差能量表”，用它判断系统误差是不是持续下降。

### 2. 当前误差能量项

```text
V₁=e^(2αt)eᵀP_m e
```

含义：刻画当前时刻误差能量。

作用：直接衡量现在误差大不大。

### 3. 实际时变时滞区间的历史误差项

```text
V₂=∫_{t−τ(t)}^t e^(2αs)eᵀ(s)Q_m e(s) ds
```

含义：刻画实际时变时滞区间内的历史误差影响。

作用：处理 `e(t−τ(t))` 这种历史状态项。

### 4. 最大时滞区间的历史误差项

```text
V₃=∫_{t−h}^t e^(2αs)eᵀ(s)R_m e(s) ds
```

含义：刻画最大时滞范围 `[t−h,t]` 内的历史误差影响。

作用：给时滞项一个统一上界，便于推矩阵不等式。

### P11 与上文的关系

P10 得到了闭环误差系统，P11 就是针对这个闭环系统构造 Lyapunov 泛函。

最后如果能找到正定矩阵和控制增益，使：

```text
Ω_m < 0
```

就说明 Lyapunov 能量下降，从而推出 P9 的控制目标成立。

换句话说：

```text
P10 的闭环误差系统 + P11 的 Lyapunov 泛函和矩阵不等式
→ 证明闭环误差均方指数稳定
→ 实现 P9 提出的弹性均方指数同步目标
```

## 如何串起 PPT 第一、第二、第三、第四部分

答辩时可以这样讲：

> 本文先从实际 CPS 网络中的三个非理想因素出发：恶意攻击导致拓扑随机切换，通信过程带来时变时滞，执行器或输入通道存在退化。
>
> 第二部分把这些因素统一写进复杂动态网络模型，并通过参考轨迹和同步误差，把同步问题转化为误差系统的均方指数稳定问题。
>
> 第三部分针对这个误差系统设计模态依赖状态反馈控制器，使控制增益可以随当前拓扑模态调整。然后将控制律代入误差系统，得到闭环误差系统。
>
> 为了证明闭环系统稳定，构造 Lyapunov--Krasovskii 泛函，同时处理当前误差、时滞历史误差和最大时滞范围内的误差。
>
> 最后通过矩阵不等式判据保证误差均方指数收敛。第四部分仿真就是验证：在有攻击、时滞和输入退化的情况下，加入控制器后同步误差明显下降，从而说明所设计控制器具有弹性同步能力。

## 一句话总括

可以记成这一句：

> 我先建立含攻击、时滞和输入退化的网络模型，再把同步问题转成误差稳定问题；随后设计模态依赖反馈控制器得到闭环误差系统，最后用 Lyapunov--Krasovskii 泛函和矩阵不等式证明闭环误差均方指数收敛，并通过仿真验证控制器有效。
